Cancelar Salvar

Aberta pela engrenagem do painel, pelo botão direito ou pelo menu da bandeja. Salvar aplica na hora, sem reiniciar.

Nada de login porque o Windows já sabe o que está tocando

O app não conversa com o Spotify. Ele lê e comanda a API de mídia do próprio Windows — a mesma que aparece no volume da barra de tarefas e nas teclas de mídia do teclado.

01 · origem

Spotify ou Spotifast

Precisa do Spotify desktop ou do Spotifast instalado e tocando. O player web não publica sessão de mídia no Windows.

02 · intermediário

SMTC do Windows

Expõe título, artista, álbum, capa, posição da faixa e os comandos anterior/play/próxima.

03 · painel

Seu painel

Uma thread lê o estado e outra desenha a janela de 158 px. Nenhum token, nenhuma conta conectada.

O que ele não faz

Ferramenta pequena tem limite claro. Estes são os de hoje, medidos nesta máquina.

  • Não mostra a próxima faixa. O SMTC entrega título, artista, álbum, capa e tempo — mas não a fila. Mostrar “a seguir” exigiria a Web API do Spotify, com OAuth e conta Premium.
  • Não controla o player web. Só players que publicam sessão SMTC aparecem: Spotify desktop e Spotifast.
  • Não tem busca, playlist nem volume. É controle de faixa, não um cliente de música.
  • Ocupa ~130 MB de memória. Medido com o painel aberto: um processo nativo em Rust mais o WebView2 do sistema, sem PowerShell e sem subprocessos.
  • O ícone pode cair no “^” da bandeja. O Windows 10 esconde ícones novos; arraste para a área visível uma vez. Até lá, o atalho de mostrar/esconder resolve.
  • Uma instância só. Abrir de novo não duplica o painel; a segunda execução sai sozinha.

Baixar

Um arquivo de ~3 MB no Windows: baixou, deu duplo clique, o painel apareceu. Sem instalador, sem serviço, sem terminal e sem nada para configurar antes.

Windows · .exe

Baixar para Windows Prefiro o .zip (35 KB)
  • versão 1.2.1
  • ~3 MB
  • Windows 10 ou 11
  1. Baixe o executável

    SpotifyOverlay.exe roda de qualquer pasta, inclusive a de Downloads. O zip é só uma alternativa com o mesmo exe mais o README.txt.

  2. Duplo clique

    O painel aparece no canto superior direito e o ícone vai para a bandeja. O config.json é criado ao lado do executável.

  3. Se o Windows avisar

    “O Windows protegeu o computador” aparece porque o exe não tem assinatura de código: clique em Mais informações e depois em Executar assim mesmo. O controle de mídia é local (SMTC), sem login, token ou API do Spotify.

  4. Deixe o Spotify ou Spotifast tocando

    O app lê a sessão de mídia do Windows (SMTC) e usa o WebView2 que já vem no Windows 10/11. O player web não publica sessão; o Spotifast publica, então funciona igual ao Spotify desktop.

Confira o arquivo

SHA-256 do .exe publicado. Para conferir no Windows:

certutil -hashfile SpotifyOverlay.exe SHA256

O arquivo SpotifyOverlay.exe.sha256 acompanha cada release.

Baixar para macOS

App em Rust + Tauri, universal (Apple Silicon e Intel), ~3 MB no zip. Controla Spotify e Spotifast; os três atalhos são graváveis pressionando as teclas nas Configurações. Fora da Mac App Store e sem assinatura Developer ID, então o Gatekeeper pede um clique extra na primeira abertura.

macOS · .app universal

Baixar para macOS código-fonte
  • versão 1.2.1
  • ~3 MB
  • macOS 13 ou superior
  • arm64 + x86_64
  1. Arraste para Aplicativos

    O zip traz Spotify Overlay.app. Descompacte e mova para /Applications.

  2. Abra uma vez e libere no Gatekeeper

    O aviso aparece porque o app não é notarizado. Abra Ajustes do Sistema > Privacidade e Segurança e clique em Abrir Mesmo Assim. Desde o macOS Sequoia não existe mais o “botão direito > Abrir”.

  3. Autorize o controle do Spotify

    O macOS pergunta se o app pode controlar o Spotify (Automação). Sem isso o painel abre, mas não lê a faixa. O caminho de correção fica em Ajustes > Privacidade e Segurança > Automação. Com o Spotifast, o overlay usa a CLI local e não pede Automação.

  4. Pronto: painel no canto, ícone na barra de menus

    Mesmos três tamanhos, mesmos atalhos e o mesmo config.json da versão Windows, em ~/Library/Application Support/SpotifyOverlay. Escolha o player em Configurações > Player ou na chave player (auto, spotify ou spotifast); no auto, o overlay usa quem está tocando.

Confira o arquivo

SHA-256 do .zip publicado. Para conferir no macOS:

shasum -a 256 SpotifyOverlay-macOS.zip

O arquivo SpotifyOverlay-macOS.zip.sha256 acompanha a release.

Diferenças em relação ao Windows

  • A permissão é pedida de novo a cada atualização. A assinatura é ad-hoc, então o macOS trata cada build como um app diferente.
  • A capa usa a rede. O Spotify entrega a arte como URL e o WebView do sistema carrega a imagem só de i.scdn.co.
  • Sem fila e sem Spotify Connect. O AppleScript do app não expõe a fila nem controla outros dispositivos.
